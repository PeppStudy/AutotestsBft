Модуль ДМО пока не вышел в прод, некоторые его разделы находятся в процессе активной разработки. Поэтому наиболее целесообразным кажется частичная автоматизация для модуля в целом с полной автоматизацией для отдельных разделов.

    1. Общее: Подготовка тестовых данных для всех разделов проекта отнимает значительную часть времени. ФЛ требуются изменяемые параметры гражданства, проживания, возраста, стажа и заработка, предназначенных мер, оцифрованные конфирмдоки, включение в банки данных и т.п. В настоящее время по каждой из >20 мер модуля созданы коллекции в Postman, охватывающие полный цикл подготовки ФЛ для данной меры. Но для выполнения условий конкретных тест-кейсов приходится править параметры запросов вручную (например, заполнять данные в запросе на заработную плату за период) + Postman дает ограниченное количество запусков коллекций в бесплатной версии.
Возможное решение: Реализовать цикл запросов на создание ФЛ в виде параметризованных тестов в Rest Assured. 
Плюсы: после того как заданы изменяемые параметры, процесс запускается «одной кнопкой» и может повторяться неограниченное количество раз, выводя нужный результат (обычно это flItemId, снилс и rpuDocId), например, в Телеграм; поскольку Rest Assured - тестовая библиотека, можно настроить уровень и вид логирования в Allure с передачей в Телеграм, на случай падения отдельных запросов; изменяемые параметры можно вынести в отдельный файл или файлы, что удобно для команды: не надо разбираться в коде.
Минусы: придется поломать голову над логикой параметризации
